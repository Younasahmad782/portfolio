Source-code project · not publicly deployed

BizFlow: Business Management Platform

A multi-tenant business management application for small and medium businesses in Pakistan: customers, products, inventory, suppliers, orders, invoices, expenses and employees, with every record scoped to an organization and protected by role-based access.

Stack

  • React
  • TypeScript
  • Vite
  • Tailwind CSS
  • Node.js
  • Express
  • PostgreSQL
  • Prisma
  • Socket.IO
  • Docker

What it does

  • Multi-tenant data isolation with role-based permissions enforced on the server
  • Order confirmation runs as one database transaction: stock deduction and invoice creation, with rollback on failure
  • Every stock change recorded as an auditable inventory movement
  • PDF invoice generation with payment-derived status
  • Expenses and a profit & loss report built from database records
  • Real-time notifications per organization, plus a readable audit log
  • AI assistant that answers only from the organization’s own aggregated data

My contribution

I specified, reviewed, tested, debugged and hardened the application. It was built with AI-assisted coding, which the repository states openly, and I maintain the codebase.
