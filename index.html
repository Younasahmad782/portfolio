About

Software that fits how a business actually runs

I’m a full-stack web developer based in Lahore. I build responsive websites, dashboards and database-backed applications, and I work across the whole path: interface design, REST APIs, data modelling, testing and deployment.

My approach starts with the business problem. For BizFlow, that meant asking what a small shop owner needs to know each day (stock, unpaid invoices, expenses, profit) and designing the data model, permissions and screens around those answers rather than around features for their own sake.

I use modern AI coding tools as part of my workflow and treat their output as a draft: I review it, test it, debug it and only ship what I can explain. BizFlow’s repository documents this, including its automated tests and a security review.

Source-code project · public demo not deployed yet

BizFlow: business management platform

A multi-tenant application for small and medium businesses in Pakistan, covering customers, products, inventory, suppliers, orders, invoices, expenses and employees. Every record is scoped to an organization and protected by role-based access.

Stack

  • React
  • TypeScript
  • Vite
  • Tailwind CSS
  • Node.js
  • Express
  • PostgreSQL
  • Prisma
  • Socket.IO
  • Docker

Key features

  • Multi-tenant data isolation with role-based permissions enforced on the server
  • Order confirmation as one database transaction: stock deduction and invoice creation, with rollback on failure
  • Every stock change recorded as an auditable inventory movement
  • PDF invoices, expenses and a profit and loss report built from real records
  • Real-time notifications per organization and a readable audit log
  • AI assistant that answers only from the organization’s own aggregated data
