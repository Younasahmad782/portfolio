# Muhammad Younus — Portfolio

Personal portfolio website of **Muhammad Younus**, Web Developer based in Lahore, Pakistan.

## What's inside

- **index.html** — single-page portfolio: hero, selected work, skills, services, about, contact
- **styles.css** — warm editorial theme (paper / ink / deep green), fully responsive
- **script.js** — vanilla JS: mobile menu, scrollspy nav, reveal-on-scroll, copy-email button

## Features

- Floating + in-page **WhatsApp** buttons (wa.me/923457305226) with prefilled messages
- Email contact (`khokharunus782@gmail.com`) with copy-to-clipboard
- Project cards: BizFlow, Everyday Calculator (live), Blog Dashboard, Clinic Website, Younus Sports Hub
- SEO meta + Open Graph tags, semantic HTML, responsive down to phones

## Run locally

```bash
cd portfolio-site
python3 -m http.server 8000
# open http://localhost:8000
```

## Deploy

Any static host works (GitHub Pages, Netlify, Vercel). For GitHub Pages:
repo Settings → Pages → Deploy from branch → `main` / root.
